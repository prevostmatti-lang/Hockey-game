Tête haute ! 🏒

Regarde. Décide. Marque.

Ou joue librement

Comment jouer

  • 🕹️Zone de déplacement (moitié gauche à l’horizontale, moitié basse à la verticale) : c’est ton joystick. Pousse pour patiner (plus loin = plus vite), sur le côté pour tourner, vers le bas pour reculer.
  • 👀Zone de vision (l’autre moitié) : glisse pour regarder autour de toi. Lève le doigt et ton regard revient devant.
  • ⬆️Swipe vers le haut pour passer ou tirer, dans la direction voulue. Plus tu swipes vite, plus c’est fort ; un swipe très long fait une passe levée par-dessus les crosses.
  • 🥅Swipe vers le but : le jeu ralentit et la cage apparaît. Touche vite une cible verte (trou libre) pour tirer dedans ; les rouges sont couvertes par le gardien.
  • 🛑Lâche l’écran : tu glisses en ralentissant. Tape deux fois : tu freines.
  • ⬇️Pouce sous le point de départ : marche arrière ; au-dessus : marche avant. Le changement de sens est immédiat.
